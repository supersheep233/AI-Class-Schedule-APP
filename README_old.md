# AI 智能课表 (AI Smart Schedule)

## 📌 项目简介

**AI 智能课表** 是一款跨平台的智能课程管理应用程序。本项目的核心目标是利用先进的 AI 大语言模型（如 Kimi v2.5 的多模态视觉能力），帮助用户摆脱繁琐的手动录入，实现**“拍照即生成”**的极简课表导入体验。同时具备强大的多学期管理、可高度自定义的作息时间配置方案，以及便利的桌面小组件。
**项目由Supersheep配合AI工具开发**

## 🌟 核心功能特性

1. **🤖 AI 智能识别与导入**
   - **一键拍照解析**：上传纸质课表或教务系统截图，AI Server 自动提取并转换为结构化的数字课表。
   - **增量流式反馈**：接入大模型流式响应（Stream），手机端实时显示解析和转换的进度。
   - **智能纠错与推理**：AI 会自动处理图片中的合并单元格不规则表头、提取具体上下课时间、展平复杂的“单双周”设置。
2. **📅 灵活的课表与时间段管理**
   - **多学期自由切换**：独立记录每个学期的起止日期与开学周，互不干扰。
   - **高自由度节次配置**：支持设置每天的课程总节数（最高可达 16 节），允许自由更改每一节课的具体起止时间。
   - **午饭/晚饭休息区**：在主辅修网格中，自定义插入并显示/隐藏午休和晚休分隔条。
3. **✨ 桌面小组件 (Android/iOS Home Widget)**
   - 自动生成展示今天课表日程的原生桌面小组件。
   - 在小组件内部智能计算“已结束”、“🔥 正在上课（带倒计时）”与“⏳ 即将开始”的课程状态变化。
4. **💾 稳定且安全的本地数据处理**
   - 采用原子写入（Atomic Write）机制和多级本地自动备份机制（Local Backup），有效防止手机意外杀进程或断电造成的 JSON 数据文件损毁和丢失。
   - 支持课表数据的全量导出与导入（Share 共享与外部加载）。

## 🛠️ 技术实现方式 (Implementation)

本项目采用**前后端分离**的架构：

### 【前端层】Flutter (Dart)
- **UI 及业务逻辑**：使用 `ChangeNotifier`（通过单例 `AppState`）进行全局的轻量级状态管理，界面完全遵循 Material Design 3 规范。
- **持久化方案**：使用 `path_provider` 将所有课程实体类（Models）序列化为 JSON 格式，写入设备的沙盒持久化空间。并在读写机制上加入了 `_temp` 临时文件覆写和 `_bak` 备份文件降级读取。
- **原生通信**：通过 `home_widget` 插件与 Android/iOS 原生桌面组件建立通信，向 SharedPreference 写入课程的 JSON String。
- **Android Widget**：通过原生 Kotlin 编写 `CourseWidgetProvider.kt`，利用 `RemoteViews` 解析 Flutter 传来的 JSON 并动态渲染 HTML 文本视图。

### 【后端层】Python (FastAPI + OpenAI SDK)
- 作为连接 AI 底层平台的桥梁，位于 `server/server.py`。
- 采用 **Kimi v2.5** 视觉与文本推理两阶段融合处理方案：
  - **阶段 1**：基于 Vision 要求大模型审读图片原件，输出附带上下文的 Markdown 表格草稿。
  - **阶段 2**：将 Markdown 输出连同特定的 Prompt 指令，送入下一轮会话，要求强制输出标准化 JSON，最终通过 `application/x-ndjson` 实时流传回给 APP。
